# ASB LiftDoc

Web-based custom quotation, bill, invoice and business document management system.

## Core hierarchy
Client -> Project -> Documents
Project is optional for direct quotations.

## Core modules
- Dashboard
- Clients
- Projects
- Quotations
- Bills and Invoices
- Document Builder
- Templates
- Products and Services
- Global Search
- Terms Library
- Assets
- Archive and Trash
- Settings

## Document builder requirements
- Different design for different pages
- Unlimited dynamic middle pages
- Section-based documents
- A3, A4, A5, Letter, Legal and custom sizes
- Portrait and landscape
- Custom margins
- Image or manual header/footer
- Custom tables with merge/split
- Repeat table headers
- Automatic page overflow
- Dynamic fields
- Reusable pages and sections

## Management requirements
- Client-wise and project-wise documents
- Duplicate quotation/invoice
- Revision history
- Full-site global search
- Tags
- Archive and restore
- Audit history

## Export requirements
- Preview
- Print
- PDF
- Word DOCX
- Excel XLSX
- PNG/JPG

## Brand
Product name: ASB LiftDoc
Only the D in LiftDoc uses the red brand treatment.

## Development approach
Localhost first.
PowerShell automation.
Large milestone batches.
Build/test after each milestone.
Git checkpoints and rollback safety.
