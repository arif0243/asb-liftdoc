# ASB LiftDoc Permanent Visual Lock

The Dashboard, AppShell, left sidebar, topbar and global brand theme are fixed to the approved M1 design.

Rules:
- Never redefine the approved M1 global theme in a milestone.
- Never change Dashboard/AppShell/sidebar/topbar colors without explicit approval.
- Never append generic shared CSS that overrides the shell.
- New milestones must use module-specific selectors.
- The exact M1 stylesheet is kept as the final visual authority in globals.css.
- The sidebar navigation area must be vertically scrollable.
- Only the D in LiftDoc remains red.
