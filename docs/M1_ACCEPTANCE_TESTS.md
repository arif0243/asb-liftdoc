# M1 Acceptance Checklist

Open the local ASB LiftDoc site and verify:

1. The sidebar shows the ASB LiftDoc brand.
2. Only the letter D in "LiftDoc" is red in the wordmark.
3. The overall interface uses the centralized ASB blue/navy theme.
4. Dashboard loads without an error.
5. Sidebar navigation opens:
   - Dashboard
   - Clients
   - Projects
   - Quotations
   - Bills & Invoices
   - Documents
   - Templates
   - Products & Services
   - Archive
   - Settings
6. Each menu link opens its placeholder page.
7. The global search box is visible in the top bar.
8. Ctrl+K focuses the global search box.
9. Typing module names such as "client" or "quotation" shows quick search results.
10. Mobile/responsive sidebar can open and close.
11. No horizontal page overflow is visible at normal desktop width.
12. Production build passes.

Note:
M1 search is a UI preview only. Real client/project/document search is connected in M2.
